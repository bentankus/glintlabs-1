## Role in MAT

This is a tertiary source. It should not affect action-record selection.

Use it after:

1. Primary source: Action Planning Taxonomy workbook and generated action records.
2. Secondary sources: ACT/action-taking and psychological-safety evidence/context.
3. Tertiary source: this presentation template for packaging the recommendation into slides.

## When to use

Use when the user asks for:

- a deck
- a presentation
- slides
- a customer story
- a manager-facing action-taking readout
- a consultation-style artifact on what actions to take

## How to use

- Treat the template as a presentation/storytelling scaffold.
- Use primary taxonomy content for the actual recommended actions.
- Use secondary context for why action matters and how to frame conversations.
- Preserve the template's intended People Science / Glint consultation style.
- Do not treat the deck as an authoritative source for which action to recommend.

## Privacy and sharing

The deck appears to be an internal People Science consulting resource with customer examples and contributor notes. Do not share externally unless the user confirms it is appropriate and has handled any required sensitivity review.
