# Recommended prompts for Glint Copilot users

These are example prompts end users can type directly into Glint Copilot to
trigger the `eve-people-science` skills. They are grouped by the skill each
prompt is most likely to route to. Users do not need to name a skill; the
host routes natural-language requests automatically.

## Run a standard survey analysis (`analyze-survey`)

- "Analyze this Viva Glint export and build me a report."
- "Run the standard People Science analysis on this engagement survey."
- "I don't have my own data — use the linked sample Viva Glint dataset."
- "Break down these results by department and tenure."
- "Does this survey show any attrition risk signals?"

## Get the AI-summarized preview report (`analyze-survey-ai-preview`)

- "Give me the AI summary preview of this survey report."
- "Rebuild the staged report with People Science summaries included."
- "Summarize the top themes in this survey in plain language."

## Check whether results are safe to share (`analysis-qa`)

- "Is this analysis manifest safe to interpret and share?"
- "Check this report for small-group privacy issues before I present it."
- "Are there any statistical power or benchmark caveats I should flag?"

## Interpret findings and caveats (`interpret-analysis`)

- "What are the strongest findings in this analysis manifest?"
- "Explain the correlations between manager effectiveness and engagement."
- "What caveats should I mention when presenting these factor results?"
- "Suggest the next analysis I should run based on these outputs."

## Find published People Science guidance (`people-science-knowledge-vault`)

- "What does published People Science research say about manager trust?"
- "Find externally shareable guidance on improving survey response rates."
- "Summarize Viva Blog articles on sustaining employee engagement."

## Tips for better prompts

- Mention the file or manifest you're working with (e.g., "this export",
  "the attached manifest") so the skill can find the right input.
- Ask follow-up questions in the same conversation — skills are designed to
  chain (analyze → QA → interpret) without restating context.
- If you're unsure what to ask, start broad: "What can I learn from this
  survey?" and let the copilot suggest next steps.
